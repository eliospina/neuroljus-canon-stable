# Long-Horizon Care Intelligence

This document defines the 50-100 year research horizon for Neuroljus. It should be read together with `founder-context-and-project-thesis.md`.

## Core Frame

Neuroljus is not only a website, demo, or app concept.

It is an early research artifact for a deeper question:

How can artificial intelligence, and eventually embodied care robotics, support neurodivergent people without replacing human relationship, dignity, consent, or caregiver wisdom?

This horizon is intentionally long. It does not mean Neuroljus is currently a robotics product, clinical platform, medical device, or validated assistive technology.

## Elizabeth's Role

Elizabeth Ospina is not only the founder. In the Neuroljus model, she is the first caregiver-witness.

Her observations, questions, lived care context, and ethical pressure define what the model must learn to respect:

- communication may exist before speech
- behavior is not proof of an inner state
- repeated context matters more than isolated signals
- caregivers hold situated knowledge that cannot be replaced by AI
- dignity must be designed as a constraint, not added as branding

The project should treat caregiver knowledge as a source of structured context, not as passive user input.

## Research Direction

Neuroljus should prioritize within-person, longitudinal observation.

The project should not attempt to create broad universal claims about autism. Instead, it should ask whether careful observation over time can help identify patterns that are useful for one person, in one context, with one trusted care circle.

Useful future research units may include:

- caregiver notes
- environmental context
- routines and transitions
- sensory conditions
- optional local visual metrics
- communication attempts
- recovery patterns after distress
- caregiver interpretation and uncertainty

The purpose is not to label a person. The purpose is to improve the quality of attention around that person.

## Robotics Horizon

If Neuroljus ever moves toward robotics, the robot must be treated as an assistive care interface, not an authority.

Possible future roles for robotics may include:

- helping maintain predictable routines
- reducing environmental friction
- supporting safe handoffs between caregivers
- presenting calm communication prompts
- assisting with observation capture when consent and context allow
- helping caregivers notice repeated patterns over time

Robotics must not be framed as replacing caregivers, interpreting autistic people with certainty, or automating emotional judgment.

## Non-Negotiable Robotics Constraints

Any future robotics work must satisfy these constraints before prototyping with vulnerable people:

- explicit consent and assent model
- human override at all times
- local-first data minimization wherever possible
- no emotion, pain, or need inference as fact
- no hidden surveillance
- sensory-safe interaction design
- caregiver and autistic-person agency
- documented validation plan
- clear failure modes and stop criteria

## Decision Rule

Long-horizon work belongs in Neuroljus only if it strengthens trustworthy, ethical, useful observation without overclaiming.

If a robotics or AI feature makes the system appear more advanced but weakens dignity, privacy, consent, evidence, or caregiver agency, it does not belong in Neuroljus.

## Public Claim Boundary

Safe language:

- "future research horizon"
- "caregiver observation support"
- "communication-support research"
- "future care robotics"
- "privacy-first, non-diagnostic exploration"
- "within-person pattern documentation"

Unsafe language:

- "robot caregiver"
- "AI understands autistic people"
- "AI translates non-verbal communication"
- "detects pain, needs, or emotions"
- "clinical-ready"
- "validated care robot"
- "automated interpretation of autistic signals"

## Current Repository Meaning

In the current public repository, this horizon should influence:

- homepage positioning
- About page narrative
- privacy language
- accessibility language
- research documentation
- AI prompt boundaries
- decisions about NL-VISION

It should not be used to imply that Neuroljus currently offers a product, pilot, robotics system, clinical workflow, or validated model.
